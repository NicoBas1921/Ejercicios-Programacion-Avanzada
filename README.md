# Programación Avanzada

Repositorio académico con ejercicios y prácticas desarrolladas durante la materia Programación Avanzada.

## Contenidos

Entre los temas trabajados se encuentran:

- Programación en Java
- Interfaces gráficas con Swing
- Programación concurrente con hilos
- Comunicación mediante sockets
- Programación orientada a objetos
- Resolución de ejercicios prácticos

## Objetivo

El repositorio documenta ejercicios y prácticas realizados durante la cursada con el objetivo de aplicar conceptos de programación avanzada y fortalecer el desarrollo de aplicaciones en Java.

## Contexto

Material académico correspondiente a la Licenciatura en Informática y Desarrollo de Software.
